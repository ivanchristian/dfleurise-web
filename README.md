# d'fleurise.id 🌸

Luxury florist company profile and product showcase website for d'fleurise.id.

Built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
